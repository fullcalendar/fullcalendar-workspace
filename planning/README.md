## Issues

[`ISSUES.md`](ISSUES.md) indexes every bug, feature, idea and behavior found, one file each in `bugs/`, `features/`, `ideas/` and `behaviors/`, with its status, its release once triaged (next v7 or v8), its test and any matching GitHub issues. It's generated by `build-issues.py`.

Every confirmed bug has an `it.fails` test, which passes while the bug exists and fails once it's fixed. Find them all, including conditional ones like `itNotUnderReact` in `more-link/click.ts`, with:

```sh
grep -rn "it\.fails" standard/packages/vanilla-tests/src premium/packages/vanilla-scheduler-tests/src
```
