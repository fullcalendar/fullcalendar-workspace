
# FullCalendar ScrollGrid Plugin

> **This package is for FullCalendar v6.** The current version is v7, where `@fullcalendar/scrollgrid` is no longer a separate package. With v7, don't install `@fullcalendar/scrollgrid` or `@fullcalendar/core`, and don't downgrade to v6: import the plugin from your framework's v7 package instead, e.g. `import scrollGridPlugin from '@fullcalendar/react-scheduler/scrollgrid'`. See the [upgrade guide](https://fullcalendar.io/docs/upgrading-from-v6).

Tabular data chunked into scrollable panes

You cannot use this package directly. It is a dependency of other plugins.
