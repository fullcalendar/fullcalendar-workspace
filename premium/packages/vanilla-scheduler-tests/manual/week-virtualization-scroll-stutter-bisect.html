FullCalendar Scheduler — scroll stutter in resourceTimelineWeek with virtualization: true

Summary: In a resourceTimelineWeek view with many resource rows, scrolling the timeline body from the bottom back up to the top stutters/janks noticeably while virtualization: true (the default). Setting virtualization: false makes the same upward scroll smooth (at the cost of a heavier one-time initial render). This is plain FullCalendar with no framework and no application code — only this repo's built bundles loaded above.

Steps to reproduce: 1) Keep Virtualization checked (default) and enable all three factors below. 2) Scroll the resource rows all the way to the bottom. 3) Scroll back up quickly with the mouse wheel / trackpad → the timeline body stutters. 4) Uncheck Virtualization and repeat the same bottom→top scroll → smooth.

Isolating the cause: The checkboxes toggle contributing factors independently (each rebuilds the calendar). Starting from all factors OFF (uniform-height rows, flat event styling) the scroll is smooth even with virtualization on; enabling factors one at a time shows their impact. In our testing Variable row heights is the dominant trigger, with the two rendering-cost factors adding on top.

Variable labels (no events): a control for the above — it renders zero events and instead gives each resource cell a different number of text lines, so row heights vary purely from the spreadsheet side. If the stutter still happens here, variable row height alone (not event rendering) is the trigger. This mode takes over the calendar, so the other three factors are disabled while it's on.
