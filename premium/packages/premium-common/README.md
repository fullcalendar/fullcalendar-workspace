
# FullCalendar Premium Common

> **This package is for FullCalendar v6.** The current version is v7, where `@fullcalendar/premium-common` is no longer a separate package. With v7, don't install `@fullcalendar/premium-common` or `@fullcalendar/core`, and don't downgrade to v6: its functionality is built into each framework's v7 scheduler package, e.g. `@fullcalendar/react-scheduler`. See the [upgrade guide](https://fullcalendar.io/docs/upgrading-from-v6).

Utilities for FullCalendar's premium plugins

You cannot use this package directly. It is a dependency of other plugins.
